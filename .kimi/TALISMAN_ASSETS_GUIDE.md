# 符咒素材收集指南

> 用途: 指导如何获取64卦对应的真实道家符咒素材，替换占位符
> 关联文件: `DESIGN_SYSTEM.md` 第六章

---

## 一、为什么必须真实符咒

**占位符的局限**:
- 当前 `TalismanSVG.tsx` 基于六爻结构算法生成，有"符咒感"但非真实符箓
- 线条是几何化的，缺乏道家符咒的**云纹、讳字、罡步**等核心元素
- 对用户来说，算法生成的图案没有**祈福的心理锚定**

**真实符咒的价值**:
- 每个卦对应一种真实祈福主题（如乾卦=天官赐福、坤卦=地母护身）
- 符咒本身是东方文化中的**精神图腾**，分享时有文化仪式感
- 用户保存/分享的是"真符"，传播价值远胜算法图案

## 二、素材规格要求

### 2.1 格式与尺寸

| 项目 | 要求 | 说明 |
|------|------|------|
| 格式 | **SVG** 优先，PNG次之 | SVG可被html2canvas完美捕获，且体积小 |
| 尺寸 | 400×600px（竖版） | 与分享卡片比例匹配 |
| 背景 | **透明** 或 纯黑 `#0A0A0F` | 便于融入卡片背景 |
| 颜色 | 朱砂红 `#8B0000` + 金色 `#C8A45C` | 与设计Token统一 |
| 线条 | 矢量路径，非位图 | 保证缩放清晰 |

### 2.2 视觉规范

每张符咒应包含以下元素（参考真实道家符箓结构）:

```
┌─────────────────────┐
│  ☰  卦符号           │  ← 顶部：卦象符号
│  乾为天               │  ← 卦名（可选）
│  ─────────────       │  ← 分隔线
│                      │
│  ～～～云纹～～～     │  ← 上部：云纹/符头
│                      │
│  ┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃   │  ← 中部：主符（朱砂线条）
│  讳字/符形            │  ← 中部：核心符咒图案
│  ┃┃┃┃┃┃┃┃┃┃┃┃┃┃┃   │
│                      │
│  ～～～云纹～～～     │  ← 下部：云纹/符脚
│                      │
│  天官赐福             │  ← 底部：祈福主题/印章
│  ○ 金                │  ← 底部：五行标记
└─────────────────────┘
```

**关键元素**:
1. **符头**: 三勾、五星、日月等道家符头元素
2. **主符**: 核心符形线条（每个卦应有独特符形）
3. **符脚**: 罡步、云纹收束
4. **印章区**: 预留红色印章位置（代码层叠加）

## 五、获取渠道建议

### 5.1 推荐方式（按优先级）

| 优先级 | 方式 | 说明 |
|--------|------|------|
| 1 | **AI生成 + 人工修正** | 用Midjourney/Stable Diffusion生成符咒风格图，再矢量化 |
| 2 | **委托设计师** | 找懂道教文化的插画师定制 |
| 3 | **古籍数字化** | 从《道藏》等古籍中提取符箓，数字化重绘 |
| 4 | **开源素材** | 搜索CC0/MIT协议的道教文化素材 |

## 六、版权与文化注意事项

### 6.1 版权
- 真实古符通常属于**公有领域**（古籍），但数字化版本可能有版权
- AI生成的符咒**建议标注为"AI辅助创作"**
- 如使用设计师作品，需签署版权转让/授权协议

### 6.2 文化敏感性
- 符咒在道教文化中具有**宗教意义**，不宜随意编造
- 建议咨询道教文化研究者或道长，确保符形**不触犯禁忌**
- 可以在符咒设计中加入**通用祈福元素**（如五星、八卦、云纹），避免特定神讳
- 产品定位是"文化体验"而非"宗教法器"，需在文案中**明确免责声明**

### 6.3 建议的免责文案
```
本应用中的符咒图案为传统文化艺术再创作，
仅供文化欣赏与心理慰藉，不具备宗教法器效力。
```

## 七、占位符 → 真实素材替换流程

### 7.1 修改数据文件

编辑 `src/data/hexagram-talismans.ts`:

```ts
// 替换前
'乾为天': {
  ...
  svgPath: null,  // ← 占位符
}

// 替换后
'乾为天': {
  ...
  svgPath: '/talismans/qian-tianguan.svg',  // ← 真实素材
}
```

### 7.2 放置素材文件

```bash
cp qian-tianguan.svg public/talismans/
```

### 7.3 修改渲染逻辑

在 `TalismanSVG.tsx` 或 `SharePoster.tsx` 中:

```tsx
// 有真实素材时显示图片，否则显示占位符SVG
{hasRealTalisman(hexagramName) ? (
  <img src={talisman.svgPath} alt={talisman.blessingTheme} />
) : (
  <TalismanSVG {...props} />
)}
```
