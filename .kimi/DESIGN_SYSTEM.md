## 一、项目背景

**MysticDao** 是一款东方命理伴侣应用，核心功能：
- 每日一卦（I Ching Daily Fortune）
- 八字命盘（Bazi）
- 风水罗盘（Feng Shui Compass）
- 塔罗牌（Tarot）

**当前分支**: `v3.1-agent-rewrite` (commit `6919d86`)
**技术栈**: React 19 + TypeScript + Vite + Tailwind CSS + Framer Motion + html2canvas
**Bundle体积**: 1,813KB raw / 499KB gzip（500KB红线）

## 三、视觉定调（已投票确认）

6方向投票结果：`1:A 2:D 3:B 4:B 5:A 6:A`

| 维度 | 选择 | 含义 |
|------|------|------|
| 1. 色彩基调 | **A** | 纯黑底 + 金/红点缀（数字故宫风格） |
| 2. 质感语言 | **D** | 墨玉 + 朱砂（温润东方质感） |
| 3. 动效风格 | **B** | 粒子 + 缓动（克制，不花哨） |
| 4. 排版气质 | **B** | 书法大字 + 西文混排（国际东方） |
| 5. 图标语言 | **A** | 线条卦象 + 极简icon |
| 6. 整体氛围 | **A** | 神秘庄严（非活泼可爱） |

**总体方向**: 数字故宫风格 — 纯黑底、金书法、朱砂印章、克制动效。

## 七、符咒库架构

### 6.1 数据结构

```ts
interface HexagramTalisman {
  hexagramName: string;      // 卦名
  blessingTheme: string;     // 祈福主题（如"天官赐福"）
  category: TalismanCategory; // 8大分类
  element: string;           // 五行
  svgPath: string | null;    // 真实素材路径，null=占位符
  placeholderSeed: number;   // 占位符生成种子
}
```
