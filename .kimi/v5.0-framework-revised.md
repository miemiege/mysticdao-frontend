## 〇、用户反馈修正总结（6项核心修正）

### 修正1：符咒素材 ≠ 阻塞项 → 按需程序化生成

| 维度 | 原方案 | 修正后 |
|------|--------|--------|
| 素材来源 | 64张真实素材图（阻塞） | 程序化SVG实时生成（零预存） |
| 获取方式 | 路线A/B/C决策（困难） | 网上资料丰富，有据可依（已搜索验证） |
| 生成时机 | 全量预存 | **抽到哪个卦，生成哪个符咒** |
| 后续优化 | 无计划 | 结构正确后 → AI图片优化（Midjourney/SD） |
| Bundle影响 | 担心超500KB | **零影响**，生成逻辑仅~5KB |

**已验证的道教符咒结构资料**（来源: 搜索结果）:
- 符咒五要素: 符头、主事神佛、符腹、符胆、符脚
- 符头类型: 三清符头（三勾）、三台星君符头、敕令符头
- 符胆: 灵魂符号，常见"罡""井""马""化"等
- 符脚: 五雷/日月/十二星君收束
- 符纸: 黄色（土元素），朱砂红（纯阳能量）

### 修正2：Bundle红线 → 完全不相关

- 符咒是**运行时生成**，不进打包产物
- 唯一增加的代码: `TalismanSVG.tsx` 生成逻辑 (~3KB gzip) + 颜色数据 (~1KB gzip)
- Bundle预估增长: <5KB gzip（可忽略）
- 无需 `import()` 懒加载，无需分块

### 修正3：文化合规 → 海外推广，压力大幅降低

| 维度 | 国内推广 | 海外推广（修正后） |
|------|----------|-------------------|
| 符咒真实性 | 需极度简化，避免宗教敏感 | 可以更真实，参考真实道教结构 |
| 表述方式 | 避"驱邪/杀鬼" | 聚焦祈福/祝福/平安（positive only） |
| 免责声明 | 需强调"娱乐性质" | 标准"For entertainment only" |
| 语言 | 中文为主 | **英文为主，中英双语** |
| 应用商店分类 | 需规避宗教类 | Entertainment / Lifestyle |

### 修正4：分享卡 → 多平台真实场景适配

| 平台 | 尺寸 | 比例 | 真实使用场景 |
|------|------|------|-------------|
| **Web展示版** | 视口全屏 | 自适应 | 网站内展示，冲击力第一 |
| **Instagram Feed** | 1080×1350 | 4:5 | Feed中占最大面积，缩略图清晰 |
| **Instagram Story** | 1080×1920 | 9:16 | 全屏快拍，需预留安全区 |
| **Twitter/X** | 1200×675 | 16:9 | Timeline中辨识度高，快速阅读 |
| **微信/朋友圈** | 1080×1920 | 9:16 | 类似Story，竖版全屏 |
| **通用竖版** | 800×1200 | 2:3 | 传统符咒比例，通用下载 |

### 修正5：颜色 → 主题化（五行动态配色）

| 五行 | 主题名 | 主色 | 辅色 | 点缀 | 统一印章 |
|------|--------|------|------|------|----------|

| 木 | 青木 | `#4A7C59` | `#6B9E7A` | `#C8E6C9` | `#8B0000` |

### 修正6：符咒风格 → 仿照参考图（4张图的共同特征提取）

## 一、符咒生成引擎（TalismanEngine）— 核心基础设施

### 1.1 架构设计

```
TalismanEngine
├── 输入: hexagramName, lines[], score, date
├── 数据层: HEXAGRAM_TALISMANS (已有)
├── 生成层:
│   ├── 符头生成器 (FuHeadGenerator) — 根据分类选择符头类型
│   ├── 符腹生成器 (FuBodyGenerator) — 六爻排列 + 核心符形
│   ├── 符胆生成器 (FuGallGenerator) — 五行对应符胆字
│   ├── 符脚生成器 (FuFootGenerator) — 云纹 + 五行 + 印章
│   └── 主题色生成器 (ThemeGenerator) — 五行→颜色
└── 输出: SVG DOM → html2canvas → PNG
```

### 1.2 符头生成规则（3种真实符头）

**三清符头**（天官赐福/武运昌隆类）:
```
    ～  ～  ～
   ／  ＼／  ＼
  ｜   ｜   ｜
  三勾代表三清道祖（道德天尊/元始天尊/灵宝天尊）
  象征: 生气、无中生有、三才（精气神/日月星/水火风）
```
SVG实现: 三条贝塞尔曲线，金色描边，顶部排列

**三台星君符头**（地母护身/姻缘和合类）:
```
   ☰  ☷  ☳
   上台虚精开德星君
   中台六淳司空星君
   下台曲生司禄星君
   象征: 城隍、土地、祖师
```
SVG实现: 三个星形符号 + 文字标注

**敕令符头**（文昌启智/转运破厄/平安顺遂/财运亨通类）:
```
   敕  令
   或特殊符形变体
   象征: 天圆地方、律令九章
```
SVG实现: "敕令"书法效果（路径文字或SVG text with filter）

### 1.3 符腹生成规则（核心视觉区）

**六爻排列**:
```
  ━━━━━━━━━━━━━━━  ← 第6爻（上爻）
  ━━━━━  ━━━━━    ← 第5爻（阴爻=断线）
  ━━━━━━━━━━━━━━━  ← 第4爻
  ━━━━━  ━━━━━    ← 第3爻
  ━━━━━━━━━━━━━━━  ← 第2爻
  ━━━━━  ━━━━━    ← 第1爻（初爻）
```
- 阳爻: 实线，主题色，带微光效果
- 阴爻: 断线（两段），主题色
- 从下往上排列（初爻在底部）

**核心符形**（每个卦独特）:
基于seed生成伪随机但确定的路径:
- 乾卦（纯阳111111）→ 刚直竖线为主 + 少量横线
- 坤卦（纯阴000000）→ 波浪曲线 + 回环
- 坎卦（水010010）→ 流动S曲线 + 水滴形
- 离卦（火101101）→ 尖锐折线 + 火焰形
- 震卦（雷001001）→ 锯齿折线 + 闪电形
- 巽卦（风110110）→ 螺旋曲线 + 风涡形
- 艮卦（山100100）→ 阶梯折线 + 山峰形
- 兑卦（泽011011）→ 圆润曲线 + 波纹形

**卦名书法字**:
- 竖排，金色，书法效果（使用SVG filter: `feTurbulence` + `feDisplacementMap` 模拟毛笔质感）
- 位置: 六爻左侧或右侧

### 1.8 与AI图片优化的衔接

**程序化SVG → AI提示词映射**:

```
SVG元素位置        →  AI图片构图
─────────────────────────────────────
顶部三勾符头       →  "Three-hook Sanqing symbol at top"
中部六爻排列       →  "Six horizontal lines (3 solid, 3 broken) in center"
核心符形路径       →  "Central calligraphic talisman pattern"
底部云纹           →  "Cloud patterns at bottom"
红色印章           →  "Red cinnabar seal stamp"
金色边框           →  "Golden double-line border"
暗纹背景           →  "Subtle cloud texture on dark background"
```

**替换策略**（零代码改动）:
1. 保持 `hexagram-talismans.ts` 数据结构不变
2. AI生成图片后，填入 `svgPath: "/talismans/qian-real.png"`
3. `TalismanSVG.tsx` 检测到 `svgPath` 存在 → 渲染 `<img>` 替代 SVG
4. 未替换的卦继续用SVG生成

### 3.3 技术实现方案

**动态DOM + html2canvas**:

```typescript
// 核心流程
const generateShareCard = async (
  platform: PlatformKey,
  hexagramData: HexagramResult
): Promise<Blob> => {
  // 1. 创建隐藏容器
  const container = document.createElement('div');
  container.style.position = 'fixed';
  container.style.left = '-9999px';
  container.style.top = '0';

  // 2. 设置尺寸
  const config = PLATFORMS[platform];
  container.style.width = `${config.width}px`;
  container.style.height = `${config.height}px`;

  // 3. 渲染内容（根据layout选择组件）
  const root = createRoot(container);
  root.render(<ShareCardLayout platform={platform} data={hexagramData} />);

  // 4. 等待渲染完成
  await new Promise(r => setTimeout(r, 500));

  // 5. html2canvas截图
  const canvas = await html2canvas(container, {
    width: config.width,
    height: config.height,
    scale: 2, // 高分屏适配
    backgroundColor: '#000000',
    logging: false,
  });

  // 6. 导出PNG
  return new Promise((resolve) => {
    canvas.toBlob((blob) => resolve(blob!), 'image/png', 1.0);
  });
};
```

**性能优化**:
- 预渲染: 摇卦过程中后台预渲染通用版
- 缓存: 同卦同平台结果缓存到 `localStorage`
- 渐进加载: 先显示低分辨率预览，再生成高清版
