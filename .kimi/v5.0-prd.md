## 一、版本定位

**v5.0 = 产品重构 + 商业化基础 + 玩法升级**

从"功能完备的文化体验工具"升级为"可商业化的东方玄学生活方式产品"。

核心目标：
1. **商业化闭环**：建立订阅制收入模型

## 二、商业模式（三层收入模型）

### 2.1 订阅制 — "灵枢会员"

| 等级 | 价格 | 权益 |
|------|------|------|
| **免费试用** | ¥0 | 每日1卦基础解读（N/R稀有度）、罗盘基础功能、3次八字排盘 |
| **月会员** | ¥18/月 | 每日无限抽卦、SSR卦卡解锁、AI深度解读、八字详批2次/月、专属主题 |
| **年会员** | ¥168/年（≈¥14/月）| 月会员全部权益 + 年度运势报告 + 流年飞星 + 优先客服 + 周边9折 |
| **终身会员** | ¥688 一次性 | 全部永久权益 + 限定"太极"身份标识 + 1v1命理师咨询1次 |

**会员权益设计原则：**
- 免费用户能"尝到味道"但处处有天花板（每天只能抽1次、看不到详细解读）
- 付费用户的"爽点"要可视化：SSR卦卡的金边闪光、专属主题的黑金配色、AI解读的深度感
- 年会员的ROI要明显：买10个月送2个月，送年度报告（价值感高、边际成本低）

**付费墙设计（关键转化点）：**
- 第3天：弹窗"解锁深度解读，首月半价 ¥9"
- 抽到SSR时："SSR卦卡仅限会员收藏，立即解锁"
- 八字详批第3次："本月免费次数已用完，会员无限次"
- 分享海报时：底部小字"灵枢会员专属 · 去广告"

### 2.2 单次付费 — "八字详批" + "合婚分析"

| 服务 | 价格 | 内容 |
|------|------|------|
| **八字精批** | ¥38/次 | 四柱排盘 + 十神分析 + 大运流年 + 喜用神 + 事业/感情/财运专项 |
| **八字合婚** | ¥58/次 | 双人八字 + 合婚分数 + 相处建议 + 化解方案 |
| **起名服务** | ¥68/次 | 中文起名（10组）/ 外国人中文名（5组）+ 详细解析 |
| **风水布局** | ¥88/次 | 房间分析 + 家具摆放建议 + 颜色方案 + 年度吉位 |
| **年度运势** | ¥128/次 | 全年12月逐月分析 + 流月飞星 + 关键节点提醒 |

**定价逻辑：**
- 八字精批 ¥38 = 一杯奶茶钱，决策门槛低
- 起名 ¥68 = 市面上线下起名 ¥200-500 的1/3，有性价比优势
- 年度运势 ¥128 = 年会员 ¥168 的钩子，"不如直接买年会员"

## 四、功能模块深化设计

### 4.1 风水相机预告页（FengshuiCamera Teaser）

**产品定位：** "看起来像是苹果Vision Pro级别的空间扫描功能"，实际为Coming Soon预告页，制造期待感 + 收集邮箱。

**三屏结构：**

**屏1 — 概念展示**
- 视觉：高斯模糊的建筑/房间概念图，金色粒子缓慢漂浮
- 文案："AI风水相机 · 即将开启" / "扫描你的空间，获取专属风水能量图"
- CTA：脉冲发光的"立即体验"按钮
- 心理：让用户觉得"这个功能很酷，我想试试"

**屏2 — 模拟扫描**
- 请求摄像头权限（真实打开摄像头）
- 摄像头画面 + HUD网格 + 扫描线动画
- 进度条：0% → 100%，显示"正在分析空间能量场..."
- 心理：给用户"我正在被AI分析"的参与感，即使功能未开放

**屏3 — Coming Soon**
- mock结果卡片：模糊的3D房间俯视图 + 八卦标注 + 五行能量条
- 大字："完整功能即将上线"
- 邮箱输入："留下邮箱，第一时间体验"
- 社交分享："分享给朋友，一起期待"
- 心理：制造FOMO（错失恐惧），让用户主动留下信息并传播

**数据目标：**
- 邮箱收集率 ≥ 30%
- 分享率 ≥ 15%

### 4.2 每日一卦 v2（核心留存引擎）

**产品定位：** 用户"每天打开的理由"。

#### 4.2.1 仪式升级

**五感体验设计：**
- **视觉**：铜钱飞行动画（3D旋转+抛物线+弹跳）、卦象SVG逐笔绘制
- **听觉**：Web Audio API程序化生成——竹筒摇晃（白噪声+低通）、铜钱碰撞（金属衰减正弦波）、卦象揭示（和谐和弦）
- **触觉**：手机震动反馈（Android支持，iOS静默跳过）
- **时间**：每日限定时段抽卦有加成（子时23-1点抽卦=SSR概率+5%）

#### 4.2.2 集卡系统（Gamification核心）

**稀有度三层模型：**

| 维度 | 规则 | 代码实现 |
|------|------|----------|
| **① 爻变随机** | 0爻=N / 1-2爻=R / 3-4爻=SR / 5-6爻=SSR | 纯数学概率 |
| **② 八字加成** | 喜用神五行对应的卦，SSR概率+20% | 读取localStorage八字数据 |
| **③ 日期限定** | 特定节日出限定卦 | 硬编码节日-卦映射表 |

**日期限定卦表：**
- 立春（2月3-5日）→ 复卦（地雷复，万物始生）
- 春节（正月初一）→ 乾卦（天行健）
- 元宵（正月十五）→ 离卦（火）
- 清明 → 巽卦（风，清明时节雨纷纷）
- 端午 → 坎卦（水，龙舟）
- 七夕 → 离卦（火，姻缘）
- 中秋 → 泰卦（天地交泰，团圆）
- 重阳 → 艮卦（山，登高）
- 冬至 → 坤卦（地势坤，一阳初生）
- 腊八 → 既济卦（水火既济，年终圆满）

**签到 streak 系统：**
- 连续7天 → 解锁"金边框"主题
- 连续30天 → 解锁"太极"主题 + 1次免费八字详批
- 连续100天 → 解锁"龙纹"主题 + 终身会员折扣码
- 断签惩罚：streak归零，但可用"补签卡"（看广告/分享获得）

**卦卡册 UI：**
- 4×N 网格，已收集亮、未收集暗
- 点击翻转（正面卦象/背面详情）
- 筛选：全部/N/R/SR/SSR/限定
- 进度条："12/64 已收集 · 1/10 限定"

#### 4.2.3 运势PK（裂变引擎）

**机制：**
- 用户A抽完卦后，生成邀请链接
- 链接包含A的卦象数据（Base64编码）
- B打开链接 → 显示A vs B的运势对比
- 胜负判定：分数高低 + 五行生克关系

**五行生克文案库：**
- A生B → "你的【卦A】滋养了对方的【卦B】，今日你旺Ta"
- A克B → "你的【卦A】压制了对方的【卦B】，今日你占上风"
- A被B克 → "对方的【卦B】克制了你的【卦A】，今日宜低调"
- 相同 → "同卦相求，志趣相投，今日有缘"

**传播钩子：**
- "你的运势击败了73%的朋友"
- "生成你的反击链接，打败Ta！"
- 分享卡片：双方卦象对比图，适合朋友圈

#### 4.2.4 匿名社区（轻量社交）

**"今日灵签榜"：**
- 显示6-8个匿名用户的今日卦象（前端随机生成，基于当日seed）
- "今日有128人和你同卦" → 制造归属感
- "同卦有缘人"标签 → 轻社交触发

**实现：** 纯前端， seeded random（同一天所有人看到相同内容），localStorage缓存。

#### 4.2.5 对话式解读

**从"公告"到"对话"：**
- 第一段：总评（始终展开，一句话）
- 后续段落：折叠，点击展开
- 底部追问按钮："💼 事业" "💕 感情" "⚠️ 注意"
- 点击后追加针对性解读（预设文案组合）
- 最多3轮追问，然后"今日解读完毕 ☯"

**追问文案生成逻辑：**
- 预置30-50条事业/感情/注意事项文案
- 根据当日卦象五行属性筛选匹配文案
- 随机组合，确保每次体验有差异

## 六、竞品差异化

| 竞品 | 优势 | 劣势 | 我们的差异化 |
|------|------|------|-------------|
| **测测** | 功能全、用户多 | UI老旧、付费墙生硬 | 东方美学+游戏化 |
| **准了** | 社交属性强 | 解读质量参差 | AI深度解读+仪式感 |
| **灵机妙算** | 师傅真人咨询 | 贵（¥200+/次）| AI替代真人，¥38/次 |
| **寺庙类App** | 祈福功能 | 功能单一 | 玄学工具+电商闭环 |
| **ChatGPT算命** | 免费、灵活 | 无仪式感、无留存 | 产品化体验+集卡+社区 |

**核心差异点：**
- **美学差异**：黑金视觉体系，市面上没有第二个
- **仪式差异**：铜钱飞行动画+音效+震动，五感体验
- **游戏差异**：集卡+PK+签到，竞品没有游戏化
- **电商差异**：AI推荐→周边购买，工具到消费的闭环
