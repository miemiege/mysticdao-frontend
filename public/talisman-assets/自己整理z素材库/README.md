## 生成流程

- **10轮循环**：每轮5分类×8张 + 参考图4张 = 36张/轮
- **5个生成Agent**：书法/纹样/纹理/印章/参考图并行生成
- **1个质检Agent**：每轮生成后即时质检，不合格自动返工
- **全链路质检**：纹理ΔE<30、印章红色>30%、书法清晰度>80

## 质量标准

- **纹理**: 暖黄宣纸色 #f9f4ed，ΔE<30
- **印章**: Alpha透明通道，朱砂红占比>30%
- **书法**: 清晰度>80，对比度>0.3
- **纹样**: 清晰度>20，图案占比>2%
