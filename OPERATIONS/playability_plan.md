## 一、核心轻互动设计（P0）

### A. 「每日一签」Daily Oracle

> *"不是给用户一条运势，是给用户一个早上打开你的理由。"*

#### 用户旅程

```
推送触达（8:00） → 打开App → 看到签筒 → 点击摇晃 → 签文弹出 → AI解读 → 生成卡片 → 分享
```

#### 交互流程图（文字描述）

```
┌─────────────────────────────────────────────────────────────┐
│  [入口：玻璃拟态卡片，显示"今日签文待启"]                     │
│       ↓ 点击                                                  │
│  [签筒放大至屏幕中央，背景暗化]                               │
│       ↓ 摇晃（陀螺仪或手指滑动）                              │
│  [Framer Motion shake：rotate ±8°，yoyo 6次，0.6s]          │
│       ↓ 签筒口金光一闪                                        │
│  [金色光点从筒口射出，签文卡片从底部滑入]                     │
│       ↓ 展示签文（上签/中签/下签 + 古文 + 白话解）            │
│  [底部 CTA："AI 深度解读" / "生成分享卡片"]                   │
└─────────────────────────────────────────────────────────────┘
```

#### 视觉设计要点

- **签筒**：深空黑底色 + 古铜金描边，筒身用极细线刻八卦符号，筒口内层做径向渐变发光（`radial-gradient(circle at 50% 0%, rgba(200,164,92,0.3), transparent)`）
- **签文卡片**：纵向卷轴感，顶部微卷角（`border-radius: 8px 8px 2px 2px`），纸质纹理叠加 `mix-blend-mode: overlay`，金色印章用 SVG 盖在右下角
- **稀缺感设计**：卡片底部一行小字"今日签文将于 00:00 更新，过期不候"，字体 `text-[10px] text-[#C8A45C]/40 tracking-widest`

#### 技术实现建议

```tsx
// 摇晃动画（Framer Motion）
const shakeVariants = {
  shake: {
    rotate: [0, -8, 8, -8, 8, -4, 4, 0],
    transition: { duration: 0.6, ease: "easeInOut" }
  }
};

// 签文弹出
const revealVariants = {
  hidden: { y: 100, opacity: 0, scale: 0.9 },
  visible: {
    y: 0, opacity: 1, scale: 1,
    transition: { type: "spring", stiffness: 120, damping: 14, delay: 0.3 }
  }
};
```

- 签文数据：前端预置 60 条签文池（20 上签 / 20 中签 / 20 下签），按日期 `hash(birthDate + date)` 确定性抽取，保证同一用户同一天结果一致
- 每日刷新：`localStorage` 记录 `lastOracleDate`，UTC+8 00:00 对比重置
- 音效：签筒摇晃用 0.3s 短促木块声（Web Audio API 或 `<audio preload>`），用户可关

#### 成功指标

| 指标 | 目标 | 追踪方式 |
|------|------|----------|
| 每日打开率 | > 25%（DAU/MAU） | `localStorage` 每日访问标记 |
| 摇晃完成率 | > 70%（点击签筒→看到解读） | 埋点：`oracle_start` → `oracle_complete` |
| 分享率 | > 5% | 埋点：`oracle_share_click` |

### B. 「抽符 / 抽牌」Talisman & Tarot Draw

> *"符咒不是图片，是'能量'的容器。用户抽到的瞬间，必须感受到'东西进手里了'。"*

#### 用户旅程

```
进入抽符页 → 看到牌背/符阵 → 点击"启封" → 3D翻转动画 → 展示牌面 → 解析 → 收藏/分享
```

#### 交互流程图（文字描述）

```
┌─────────────────────────────────────────────────────────────┐
│  [背景：暗色符阵底纹，7张牌背呈扇形排列或3×3矩阵]             │
│       ↓ 用户点击任意一张牌背                                  │
│  [其余牌淡出（opacity 0.3, scale 0.9），被点中牌居中放大]     │
│       ↓ 翻转（perspective 800px, rotateY 180°）               │
│  [牌背翻转至正面，持续 0.8s，ease: [0.4, 0, 0.2, 1]]        │
│       ↓ 翻转中途触发「能量流动」微动效                        │
│  [CSS shimmer 沿牌面纹理滑过，时长1.5s]                       │
│       ↓ 牌面完全展示                                          │
│  [符咒图案浮现 + 寓意标题 + 白话解析 + 「收藏」按钮]          │
│       ↓ 底部CTA                                               │
│  [「重新启封」（灰色/带锁图标，提示"分享解锁"）]              │
└─────────────────────────────────────────────────────────────┘
```

#### 视觉设计要点

- **牌背设计**：不同等级解锁不同牌背样式
  - 默认：暗纹太极图案
  - 修行者：云纹鎏金
  - 大师：龙鳞底纹
  - 宗师：空白宣纸质感（最高级的留白）
- **符咒 shimmer 效果**：

```css
@keyframes shimmer {
  0%   { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}
.talisman-shimmer {
  background: linear-gradient(
    90deg,
    transparent 0%,
    rgba(200,164,92,0.15) 50%,
    transparent 100%
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s ease-in-out;
}
```

- **能量流动感**：牌面展示后，四周添加极细金色粒子沿边框缓慢环绕（`stroke-dasharray` SVG 动画，8s 一圈）

#### 技术实现建议

```tsx
// 3D 翻转（Framer Motion + CSS perspective）
const flipVariants = {
  front: { rotateY: 0 },
  back:  {
    rotateY: 180,
    transition: { duration: 0.8, ease: [0.4, 0, 0.2, 1] }
  }
};

// 其他牌淡出
const siblingVariants = {
  inactive: {
    opacity: 0.3,
    scale: 0.9,
    filter: "blur(2px)",
    transition: { duration: 0.4 }
  }
};
```

- 限免机制：`localStorage` 记录 `dailyDrawUsed`，每日首次免费，后续需要分享或观看"解锁"（实际是引导付费的软墙）
- 牌池：预置 22 张大阿卡纳 + 36 张东方符咒（共 58 张），用 `seedrandom` 按日期确定抽取
- 收藏：`localStorage` 维护 `myCollection` 数组，注册后通过 Supabase 同步

| 指标 | 目标 | 追踪方式 |
|------|------|----------|
| 抽符完成率 | > 60% | 埋点：`draw_start` → `draw_reveal` |
| 重新抽取触发率 | > 15% | 埋点：`draw_retry_click` |
| 收藏率 | > 20% | 埋点：`draw_favorite` |

### C. 「运势速测」Quick Energy Check

> *"Mike 只给 10 秒。第一句说中他，他就留下。"*

#### 用户旅程

```
首页入口 → 选择星座或输入生日 → 进度动画（3-8s）→ 结果卡片 → 分享/保存
```

#### 交互流程图（文字描述）

```
┌─────────────────────────────────────────────────────────────┐
│  [入口：玻璃卡片 "测测你今天的能量场" ]                       │
│       ↓ 点击                                                  │
│  [简洁表单：日期选择器 + 时间选择器（可选）]                  │
│       ↓ 提交                                                  │
│  [全屏加载：太极旋转 + 五行元素依次点亮]                      │
│       ↓ 3-8s（前端控制，非真实计算延迟）                     │
│  [结果页：五行饼图 + 能量条 + 今日宜忌标签 + 一句话解读]      │
│       ↓ 用户向下滚动                                          │
│  [详细解读（前3条免费，第4条模糊化 + 付费墙预览）]            │
└─────────────────────────────────────────────────────────────┘
```

#### 视觉设计要点

- **加载动画**：太极 SVG 居中慢速旋转（`duration: 3s, ease: linear`），周围 5 个五行元素（金木水火土）依次从 0.2 opacity 脉冲至 1.0，每个间隔 0.6s，营造"计算中"的仪式感
- **五行饼图**：用 `recharts` 或 SVG 绘制，配色
  - 金 `#C8A45C`（古铜金）
  - 木 `#4A7C59`
  - 水 `#3B82F6`
  - 火 `#DC2626`
  - 土 `#8B6914`
  缺行用 15% opacity 表示，主行加发光阴影
- **能量条**：水平进度条，背景 `rgba(255,255,255,0.05)`，填充色根据五行主色动态取色，动画 `width: 0% → N%` 持续 1s，ease: `[0.16, 1, 0.3, 1]`
- **今日宜忌标签**："宜"用金色细边框 + 金色文字，"忌"用 `rgba(248,113,113,0.6)` 细边框 + 淡红文字，标签圆角 `rounded-full px-3 py-1 text-xs`

#### 技术实现建议

```tsx
// 五行依次点亮
const elementVariants = {
  hidden: { opacity: 0.2, scale: 0.8 },
  active: {
    opacity: 1,
    scale: 1,
    transition: { duration: 0.6, ease: "easeOut" }
  }
};

// 能量条填充
<motion.div
  initial={{ width: 0 }}
  animate={{ width: `${energyPercent}%` }}
  transition={{ duration: 1, ease: [0.16, 1, 0.3, 1], delay: 0.5 }}
  className="h-2 rounded-full"
  style={{ backgroundColor: elementColor }}
/>

// 结果卡片 stagger 入场
const containerVariants = {
  hidden: {},
  visible: {
    transition: { staggerChildren: 0.15, delayChildren: 0.2 }
  }
};
const itemVariants = {
  hidden: { opacity: 0, y: 20 },
  visible: { opacity: 1, y: 0, transition: { duration: 0.6 } }
};
```

- 结果文案公式：
  - 第 1 条必须用第二人称 `"你倾向于..."` 或 `"你最近可能感受到..."`
  - 第 2 条给具体场景 `"在团队合作中，你更适合..."`
  - 第 3 条给行动建议 `"今天适合在东南方位做重要决定"`
- 伪计算：前端根据出生日期计算八字日主 → 查表映射五行强弱 → 按日期偏移微调，全程 < 50ms，加载动画纯粹是"仪式感延迟"

| 结果页停留时间 | > 20s | 埋点计时 |

## 二、社交分享机制（P0）

### 专属海报设计规范

#### 三尺寸适配

| 比例 | 用途 | 画布尺寸 | 安全区 |
|------|------|----------|--------|
| 9:16 | Instagram Story / 抖音 / 小红书图文 | 1080×1920 | 顶部 200px 避系统栏，底部 250px 避按钮 |
| 1:1 | Instagram Feed / 朋友圈 | 1080×1080 | 中心 800×800 主内容区 |
| 4:5 | 小红书 Feed | 1080×1350 | 顶部 150px，底部 200px |

#### 海报元素层级（从底到顶）

```
Layer 0: 背景纹理（宣纸质感或星空渐变，透明度 8-12%）
Layer 1: 品牌水波纹装饰（底部 1/4，极淡金色）
Layer 2: 主内容区（符咒图案 / 塔罗牌面 / 五行饼图，居中偏上）
Layer 3: 用户昵称（"Sarah 的今日能量"，font-light tracking-wider）
Layer 4: 核心文案（签文 / 运势摘要，最大字号，serif 字体）
Layer 5: 辅助信息（宜忌标签 / 日期，font-normal text-sm）
Layer 6: 品牌栏（底部：MysticDao logo + 二维码 + 一句品牌语）
```

#### 审美标准

- **留白规则**：四边至少留 60px 空白，文字行高 1.6，段间距 > 字间距
- **字体搭配**：标题用 Georgia/Cambria serif，正文用系统无衬线，英文标题全大写 + `tracking-[0.2em]`
- **色彩克制**：主色不超过 3 种（深空黑底 + 古铜金 + 1 个五行主色点缀）
- **拒绝任何**：渐变文字、描边字、发光字、表情包、emoji（保持高级感）

#### 技术实现建议

```tsx
// 海报生成组件（html2canvas 方案）
import html2canvas from 'html2canvas';

async function generatePoster(type: 'story' | 'feed' | 'xhs') {
  const el = document.getElementById(`poster-${type}`);
  if (!el) return;

  const canvas = await html2canvas(el, {
    scale: 2,           // 视网膜屏清晰度
    backgroundColor: '#0A0A0F',
    logging: false,
    useCORS: true,
  });

  const blob = await new Promise<Blob>((resolve) =>
    canvas.toBlob((b) => resolve(b!), 'image/png')
  );

  // Web Share API（移动端原生分享）
  if (navigator.canShare && navigator.canShare({ files: [new File([blob], 'mysticdao.png', { type: 'image/png' })] })) {
    await navigator.share({
      files: [new File([blob], 'mysticdao.png', { type: 'image/png' })],
      title: 'My MysticDao Reading',
    });
  } else {
    // 降级：下载
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url; a.download = 'mysticdao-reading.png';
    a.click();
  }
}
```

- **性能**：海报 DOM 预渲染在屏幕外（`position: fixed; left: -9999px`），生成时直接截图，目标 < 2s
- **降级方案**：html2canvas 在部分浏览器有兼容问题，备用 `dom-to-image-more`，两者包体积均 < 100KB
- **二维码**：使用 `qrcode` 库生成 `https://mysticdao.app/?ref=USER_ID`，带追踪参数

### 分享激励机制

| 分享行为 | 奖励 | 技术实现 |
|----------|------|----------|
| 分享到 Instagram Story | 解锁"详细版解读"（当日有效） | 分享后返回 App，检测 `document.visibilityState` 从 hidden→visible，自动解锁（信任机制，不做强制验证） |
| 分享到朋友圈 | +20 灵力值 | 埋点 `share_moments`，`localStorage` 累计灵力值 |
| 邀请好友（双方各得） | 高级体验券（7 天会员） | 生成 `?ref=USER_ID` 链接，被邀请人首次完成排盘后双方各得券 |

## 三、用户成长体系（P1）

## 四、对标分析与差异化（P2）

### 竞品可玩性拆解

| 竞品 | 核心可玩性 | 可借鉴点 | 局限性 |
|------|-----------|----------|--------|
| **求神马**（微信小程序） | 极简每日一签，3 秒出结果 | 速度即体验；不要教育用户，直接给结果 | 无分享设计、无成长体系、无付费点 |
| **测测星座** | 星盘档案 + 社区讨论 | 档案沉淀带来留存；UGC 社区增加粘性 | 界面信息过载；社区质量参差；东方元素缺失 |
| **Co-Star** | 每日推送的文学感文案 | 文案是核心产品，不是附属；" today you might feel..." 第二人称直击 | 无互动仪式，纯阅读；无分享卡片 |
| **The Pattern** | 关系分析（双人合盘） | 关系场景是强付费动机；"我和 TA" 比"我自己"更有传播力 | 加载慢；东方用户文化隔阂 |
| **准了** | 名人星盘事件验证 | 用"已验证"建立信任感；时事关联度高 | 界面传统；海外用户无法使用 |

1. **视觉差异**：求神马像庙会，测测像工具书，Co-Star 像诗集。MysticDao 要像"数字神庙"——留白、克制、每一帧都有呼吸感。
2. **内容差异**：竞品给用户"看"，我们让用户"抽"、"摇"、"启封"。AI 生成专属符咒是独家资产，每次生成结果唯一，天然具备收藏价值。
3. **一站式差异**：西方用户知道星座但不懂八字，东方用户懂八字但想尝试塔罗。MysticDao 不做选择题，把两套体系做"翻译"（"你的八字日主是甲木，对应塔罗中的魔术师"），创造跨文化认知增量。

## 七、Mira 的最终提醒

> *"可玩性不是加小游戏。可玩性是让'使用产品'这件事本身就变成一种仪式。"*
>
> 1. **宁慢勿快**：动画时长不要压缩到 0.2s，用户需要感知到"过程"。签筒摇晃 0.6s 不是浪费，是价值。
> 2. **少即是多**：不要给用户 10 个功能入口。首屏只放 3 个：每日一签、运势速测、我的档案。其余的藏在"更多"里。
> 3. **截图即设计**：每一个可分享的页面，在设计阶段就要想象它被截图后的样子。截图不好看 = 不会分享 = 飞轮不转。
> 4. **数据要诚实**：埋点从第一天就做好。哪个环节流失了 50% 用户，比哪个功能上线了更重要。
