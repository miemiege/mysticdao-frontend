## 一、六平台内容差异化与导流路径（P0）

### 策略框架

每条内容必须回答三个问题：**谁在看？什么情绪驱使他们点开？分享后他们获得了什么社交货币？**

六平台不追求"同一个内容发六次"，而是"同一个产品，六种人格"。

## 二、裂变机制设计（P0）

### 核心公式

```
老带新 = 老用户人数 × 参与率 × 拉新效率 × 转化率
```

增长不是漏斗，是飞轮。每一次裂变都要让分享者获得"社交货币"，让接收者获得"即时价值"。

### 2.1 裂变引擎 A：分享解锁（Share-to-Unlock）

**策略框架**
免费获得基础运势 → 分享海报到朋友圈/Story → 解锁详细版 AI 解读 + 高清符咒壁纸

**具体执行步骤**
1. 用户完成一次基础排盘/抽卦，结果页展示"基础版"（50%信息）
2. 底部浮现 CTA："解锁完整 AI 解读 + 专属高清壁纸"，附带预览图（模糊处理）
3. 点击后弹出分享面板：微信朋友圈 / Story / 保存海报 / 复制链接
4. 分享完成后自动解锁：详细解读 + 无水印高清壁纸 + 分享人专属编号

**海报设计原则**
- 必须让用户觉得"分享出去有面子"——不是广告，是审美表达
- 包含：卦象名 + 金句 + 符咒视觉 + 用户专属编号（"第 8,234 位探索者"）
- 底部极小字："generated by mysticdao.com"，不喧宾夺主
- 视觉风格：东方极简 / 暗黑神秘，两个版本轮换测试

**关键指标**：分享完成率 > 15%；通过海报回流注册率 > 8%
**工具推荐**：html2canvas（前端生成海报）、Cloudflare KV（记录分享状态）

### 2.2 裂变引擎 B：邀请码裂变（Referral Code）

**策略框架**
每位用户生成专属邀请码 → 邀请 3 位好友注册 → 双方各得"高级牌阵体验券"

**具体执行步骤**
1. 首次使用后自动生成邀请码（6位字母数字，可读性强）
2. 进度可视化："已邀请 1/3 人，再邀请 2 人解锁大师版解读"
3. 被邀请人注册后，双方即时收到奖励通知（动画+音效强化爽感）
4. 邀请排行榜：周榜 Top 10 额外获得实体符咒周边抽奖资格

**奖励阶梯设计**

| 邀请数 | 邀请人奖励 | 被邀请人奖励 |
|--------|-----------|-------------|
| 1人 | 高级牌阵体验券 ×1 | 首单 50% off |
| 3人 | 月度会员 7 天 | 高级牌阵体验券 ×1 |
| 5人 | 定制化符咒壁纸 ×1 | 首单免费 |
| 10人 | 实体符咒周边（限量） | 月度会员 7 天 |

**关键指标**：邀请码分享率 > 10%；人均邀请成功数 > 1.5
**工具推荐**：邀请码可用短链形式（如 `mysticdao.com/r/SARAH88`），后端用 Cloudflare D1 记录关系

### 2.3 裂变引擎 C：社群裂变（Community Growth）

**策略框架**
微信社群（国内）+ Discord 社群（海外），以"稀缺性"和"归属感"驱动拉新

**国内：微信社群**
- 入群门槛：完成一次排盘后弹出入群二维码
- 每日运营：早上 8:00 推送"今日运势提醒"（纯文字，不打扰）
- 限量福利："今日前 10 名发送邀请码截图，免费塔罗问答"
- 裂变机制：群成员邀请 1 人入群，双方获得"明日优先问答权"

**海外：Discord 社群**
- 频道架构：#daily-reading（每日卦象讨论）、#talisman-showcase（符咒分享）、#bazi-help（八字互助）
- 身份体系：根据活跃度和邀请数分配角色（Novice → Seeker → Adept → Sage）
- 专属内容：每周五"Sage Hour"——高活跃用户可预约 1v1 AI 解读

**关键指标**：社群 7 日留存 > 40%；社群成员→付费转化率 > 5%
**工具推荐**：微信群用 wetool/企微；Discord 用 Carl-bot 自动化

### 3.2 落地页内容策略

每个落地页必须包含：
1. **标题前 20 字必须包含关键词**（H1 标签）

4. **相关内链**："测完五行，再看看你的今日运势"——增加 PV
5. **Schema Markup**：FAQ 结构化数据，争取 Google 精选摘要

**页面性能要求**
- 首屏加载 < 1.5 秒（Cloudflare CDN + 图片 WebP/AVIF）
- 移动端优先（> 70% 搜索流量来自移动设备）
- Core Web Vitals：LCP < 2.5s, FID < 100ms, CLS < 0.1

## 四、付费转化漏斗（P1）

### 策略框架

四层漏斗，每层对应不同用户心态。首单必须是 $4.99——不是因为它能赚多少，是因为它能把"免费用户"变成"付费用户"，这个身份转变比金额重要 100 倍。

### 4.1 四层漏斗设计

```
第一层（免费获客）
├── 功能：每日运势、单张塔罗、基础符咒生成
├── 目标：建立信任，培养习惯
├── 时长：Day 0-7
└── 退出条件：用户主动寻求"更多"

第二层（低价体验）
├── 产品：$4.99 "本周详细运势报告"
├── 心理："一杯咖啡钱，试试"
├── 触发点：免费结果页展示"完整版预览"（模糊/部分隐藏）
├── 支付方式：Apple Pay / Google Pay 一键支付（减少摩擦）
└── 关键动作：支付后立即展示完整结果（即时满足）

第三层（订阅制）
├── 产品：$9.9/月会员
├── 权益：解锁全部牌阵、无水印下载、每日推送、优先客服
├── 转化触发：累计购买 3 次单次解读后弹窗"订阅更划算"
├── 国内版本：微信小程序支付中间页
└── 留存设计：每周"运势周报"邮件，月末"本月能量回顾"

第四层（高客单价）
├── 产品 A：$199 "1v1 AI 命理师咨询"（30分钟视频/文字）
├── 产品 B：定制化实体符咒周边（限量，$59-129）
├── 触发点：高活跃订阅用户定向推送
├── 信任背书：用户案例、名人推荐（如有）
└── 稀缺性：每月限量 50 单
```

### 4.2 转化优化 checklist

- [x] 首单 $4.99，不是 $29.9（低门槛测试付费意愿）
- [x] 付费前给"预览"（"解锁后你将看到：①详细五行分析 ②流年运势 ③专属建议"）
- [x] 支持 Apple Pay / Google Pay / 微信支付一键支付
- [x] 关闭支付页后 24 小时邮件推送"限时 50% off"
- [x] 支付成功页展示"分享得奖励"（完成裂变闭环）
- [x] 未支付用户 7 天后推送"你的专属报告即将过期"

### 4.3 定价心理学技巧

| 技巧 | 应用 |
|------|------|
| 锚定效应 | 先展示 $29.9 的原价，再划线显示 "$4.99 限时体验" |
| 禀赋效应 | 让用户先"试用"完整版 3 秒（预览动画），再提示付费解锁 |
| 损失厌恶 | "你的专属运势报告将在 24 小时后失效" |
| 社会认同 | "本周已有 1,247 人解锁了他们的详细报告" |
| 零风险承诺 | "$4.99 不满意全额退款"（实际退费率 < 2%，信任收益极高） |

## 六、增长飞轮（文字描述）

```
                    ┌─────────────┐
                    │   优质内容   │
                    │  (六平台矩阵) │
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │   精准流量   │
                    │  (SEO+社媒)  │
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │   产品体验   │
                    │ (Aha→习惯→付费)│
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │   裂变分享   │
                    │(海报+邀请码+社群)│
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │   收入回流   │
                    │ ($4.99→$9.9→$199)│
                    └──────┬──────┘
                           │
                           └──────→ 更多内容投入 → 飞轮加速
```

**飞轮核心逻辑**：
1. **内容**是燃料——六平台差异化内容持续产出，低成本获取注意力
2. **流量**是氧气——SEO 长尾词被动获客 + 社媒主动投放，双引擎驱动
3. **体验**是转化器——30 秒内让用户说"这说得挺准"，建立信任
4. **裂变**是放大器——每次分享都是一次免费广告，且来自熟人背书
5. **收入**是加速器——收入再投入内容生产和功能优化，飞轮越转越快

**启动优先级**：P0 内容矩阵 + P0 裂变机制先行，P1 SEO + P1 付费漏斗随后。没有内容，漏斗是漏水的桶；没有裂变，增长是烧钱的游戏。
