**r/webdev / r/reactjs — 技术展示型**
```
I built an I Ching divination app with React 19 + Framer Motion + generative SVG talismans

Tech stack:
• React 19 + Vite + Tailwind
• Framer Motion for all animations
• Canvas 2D particle system (taiji-inspired)
• SVG talisman generation (no images, pure code)
• Pollinations.AI for optional image enhancement
• html2canvas for share cards

The talisman system is the most complex part — each one generates:
- A Taoist "fu tou" (符头) from 3 authentic styles
- A "fu dan" (符胆) based on the 5 elements
- A seal stamp graded by fortune score
- Background texture for "digital ink jade" feel

All in ~310KB gzipped.

AMA / Roast my code.

[link + GitHub]
```
